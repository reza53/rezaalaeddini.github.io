```R
# Step 1: Create the Student Dataset
# Load the visualization library
library(ggplot2)

# Create a simple table of measurements collected by the students
# Width and length are in millimeters. Distance is in meters.
lab_data <- data.frame(
  drop_id  = c("Drop_A", "Drop_B", "Drop_C"),
  width    = c(3.0, 4.0, 2.5),
  length   = c(6.0, 8.0, 5.0),
  distance = c(1.0, 1.5, 1.2)
)

# Step 2: Step-by-Step Trigonometry Calculations
# Find the width-to-length ratio
lab_data$ratio <- lab_data$width / lab_data$length

# Calculate the impact angle in radians using arcsin
lab_data$angle_rad <- asin(lab_data$ratio)

# Convert radians to degrees so it makes visual sense to students
lab_data$angle_deg <- lab_data$angle_rad * (180 / pi)

# Calculate the source height using the tangent function
# Height = Distance * tan(Angle)
lab_data$source_height <- lab_data$distance * tan(lab_data$angle_rad)

# Find the average height to show students the "point of convergence"
avg_height <- mean(lab_data$source_height)
```

For displaying code in a list item, you have to be aware of the indentation, as stated in this [Stackoverflow answer](https://stackoverflow.com/questions/34987908/embed-a-code-block-in-a-list-item-with-proper-indentation-in-kramdown/38090598#38090598). You must indent your code by **(3 \* bullet_indent_level)** spaces. This is because kramdown (the markdown engine used by Jekyll) indentation for the code block in lists is determined by the column number of the first non-space character after the list item marker.
