Geometric Reconstruction of Impact Spatter

Created on July 11, 2026

2026   ·   formatting   code   R-language   ·   sample-posts

In forensic science, understanding the dynamics of bloodstain pattern analysis (BPA) is crucial for reconstructing crime scene events. One of the fundamental tasks in BPA is determining the area of origin—the point in three-dimensional space from which a blood drop originated. This lab exercise introduces students to the trigonometric principles used to calculate the impact angle and source height of bloodstains. By measuring the width, length, and distance from the wall, we can apply basic trigonometry to estimate the trajectory of blood droplets and identify their point of convergence. Below, we walk through the process step-by-step using R, a powerful programming language for data analysis and visualization.

# Step 1: Create the Student Dataset
# Load the visualization library
library(ggplot2)

# Create a simple table of measurements collected by the students
# Width and length are in millimeters. Distance is in meters.
lab_data <- data.frame(
  drop_id  = c("Drop_A", "Drop_B", "Drop_C"),
  width    = c(3.0, 4.0, 2.5),
  length   = c(6.0, 8.0, 5.0),
  distance = c(1.0, 1.5, 1.2)
)

# Step 2: Step-by-Step Trigonometry Calculations
# Find the width-to-length ratio
lab_data$ratio <- lab_data$width / lab_data$length

# Calculate the impact angle in radians using arcsin
lab_data$angle_rad <- asin(lab_data$ratio)

# Convert radians to degrees so it makes visual sense to students
lab_data$angle_deg <- lab_data$angle_rad * (180 / pi)

# Calculate the source height using the tangent function
# Height = Distance * tan(Angle)
lab_data$source_height <- lab_data$distance * tan(lab_data$angle_rad)

# Find the average height to show students the "point of convergence"
avg_height <- mean(lab_data$source_height)
